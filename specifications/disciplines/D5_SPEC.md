## 2. Pedagogical Objectives

- Select Permanent Corrective Actions (PCAs) that directly eliminate the verified **occurrence**, **escape**, and **systemic** root causes established in D4.
- Distinguish required permanent corrective actions from complementary rework/containment measures (`A2`, `A6`) and ineffective/counterproductive actions (`A3`).

## 4. Required Causal Categorization

The D5 interaction design must explicitly distinguish corrective actions addressing:
1. **Occurrence** root cause
2. **Escape** (potential escape via retest release) root cause
3. **Systemic** root cause
